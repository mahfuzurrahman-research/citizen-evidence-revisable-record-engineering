# Engineering Scope

The public upgrade implements review threshold selection, held-out descriptive evaluation, label maturity checks, exact signal contracts, evidence revisions, witness-bound verification, correction recording, a positive claim allowlist, revisable claim validity, a reasoned review queue and independent DuckDB reconciliation.

The original arithmetic, lineage and benchmark companion remains runnable. Its inferred-edge benchmark now exercises the real validator, and unknown claim transitions fail closed. CSV schemas and verifier identities, finite outputs and tolerances are checked explicitly.

All records, actors, labels, signals and scenarios are fabricated here. The implementation does not reproduce the private paper's exact formal design, scientific history, parameter values or results. No manuscript, empirical data or private provenance was imported. Original authorship and copyright terms remain in place.

This is a local batch demonstration with an as-of replay. It has no production deployment, database service, user authentication, live administrative write path or automated remedy execution. A hash does not prove evidence truth; a distinct actor ID does not prove independent sources; a threshold does not authorize a correction or an expanded claim.
